# 安全、可靠性与并发检查标准

安全和可靠性发现按可利用性、数据/业务影响、暴露面、检测能力和恢复难度排序。不要用通用清单制造没有上下文的高危告警。

## 目录

1. 信任边界与资产
2. 身份与访问控制
3. 输入、输出与执行边界

## 1. 信任边界与资产

先识别：

- 身份、权限、密钥、资金、个人/租户数据和关键业务操作
- 外部入口、管理入口、Webhook、上传、插件和后台任务
- 服务、租户、网络、进程和第三方之间的信任边界
- 数据从收集、处理、传输、存储、日志到删除的生命周期
- 威胁主体及其可达路径

对 Web 系统可用 OWASP ASVS 作为覆盖参考，但只检查适用控制。

## 2. 身份与访问控制

检查：

- 认证是否验证签名、受众、签发者、过期、撤销和会话轮换。
- 授权是否在服务端、靠近资源处执行；对象级和租户级权限是否完整。
- 管理员、服务账号和后台任务是否最小权限。
- 默认账号、硬编码凭据、共享账号和长期 token。
- 密码恢复、多因素认证、设备/会话管理和敏感操作再认证。
- 缓存、批处理、导出和搜索是否绕过权限。

## 3. 输入、输出与执行边界

检查：

- SQL/NoSQL/命令/模板/表达式注入
- XSS、CSRF、开放重定向和内容类型混淆
- 路径穿越、任意文件读写、压缩炸弹和上传处理
- SSRF、DNS 重绑定、内部元数据访问和 URL 允许列表
- 不安全反序列化、动态加载、反射调用和插件隔离
- XML 外部实体、正则拒绝服务和解析器资源上限
- 日志注入、CSV/公式注入以及输出编码

验证应在信任边界发生；前端校验不能替代服务端规则。

## 4. 密钥、加密与隐私

检查：

- secret 是否出现在源码、历史、镜像、日志、错误或客户端包中。
- 传输与静态加密是否使用受支持算法和正确证书验证。
- key 生成、存储、轮换、吊销和灾难恢复。
- 自制加密、固定 IV、弱随机、可预测 token 和不安全哈希。
- 日志、追踪、备份、分析和测试数据中的敏感信息。
- 数据最小化、保留、删除、导出和租户隔离。

不要在输出中复述真实 secret；只报告位置、类型和处置建议。

## 5. 依赖与部署面

检查：

- 易受攻击或停止支持的依赖、运行时和基础镜像。
- 安装/构建脚本是否执行未固定的远程代码。
- CI token、部署身份和制品仓权限。
- 容器是否以 root 运行、暴露多余端口或包含构建 secret。
- 调试端点、管理面板、默认配置和详细错误是否暴露。
- 安全头、TLS、网络策略和来源校验是否与威胁模型匹配。

## 6. 故障语义

对每个外部调用和资源检查：

- 连接、请求和整体 deadline 是否有界
- 哪些错误可重试，退避、抖动、最大次数和重试预算
- 请求是否幂等，重试是否重复副作用
- 限流、背压、队列容量和过载保护
- 熔断、隔离舱、降级和失败缓存
- 依赖失败时是 fail-open 还是 fail-closed，是否符合业务风险
- 取消是否传播，资源是否及时释放

无超时的调用会把局部故障扩散为线程、连接和队列耗尽。

## 7. 一致性、并发与恢复

检查：

- 共享状态是否有明确同步、原子性和内存可见性规则。
- check-then-act、丢失更新、重复消费、ABA、死锁和锁顺序。
- 数据库隔离级别是否足以保护业务不变量。
- 乐观锁、唯一约束、幂等键和去重窗口是否正确组合。
- 本地事务与消息发布是否出现不可恢复的部分成功；是否需要 outbox/inbox。
- 定时任务和消费者多实例运行时是否重复执行。
- 崩溃恢复、断点续跑、补偿和人工修复路径。
- 备份的 RPO/RTO、恢复验证和跨区域/跨账号风险。

## 8. 队列与异步作业

检查：

- delivery 语义、ack 时机、可见性超时和重试上限。
- 毒消息、死信、重放、顺序、延迟和积压告警。
- 消费者是否幂等；去重存储是否有正确保留期。
- schema 不兼容时是否隔离而非无限重试。
- 批处理的部分成功、重试粒度和资源上限。
- 任务取消、超时、优先级和租户公平性。

## 9. 验证方法

按适用性组合：

- 静态安全扫描、依赖与 secret 扫描
- 权限矩阵和跨租户负向测试
- 模糊、边界和恶意输入测试
- 故障注入：超时、连接断开、重复、乱序、磁盘满
- 并发与竞态测试、数据库约束验证
- 备份恢复和 runbook 演练
- 生产级配置的安全检查

不得对真实外部目标做未经授权的攻击性测试。

## 10. 立即止血信号

- 可直接利用的认证/授权绕过
- 真实 secret 泄露或未隔离的跨租户读取
- 数据损坏正在发生且无恢复路径
- 无界重试/队列导致级联故障
- 备份不可恢复却计划执行破坏性迁移
- 高价值操作缺少幂等并已出现重复副作用

先给出隔离、禁用、限流、凭据轮换或只读保护等最小止血方案，再规划根因治理。
